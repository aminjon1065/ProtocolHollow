# Арт-пасс: как оформлять руками и ничего не сломать ([ADR-0027](../ADR/ADR-0027-art-prep-locks-tool-mount-montages-budget.md))

Порядок для каждой комнаты, инструмента и врага. Проверка всегда одна: сохрани ассет (Data Validation покажет предупреждения), перед коммитом прогони `Build/Scripts/run-tests-mac.sh --strict`.

## 1. Комнаты Доков (`LV_Docks_*`)
1. **Перед первой правкой** открой `DA_Room_Docks_<Комната>`, в разделе **Art** включи **Art Locked** и сохрани.
   - Скрипты света и звука этот уровень больше не трогают.
   - Тесты продолжают его проверять.
2. **Папки Outliner:**

   | Папка | Что там | Правило |
   |---|---|---|
   | `Geometry` | Конструкция: пол, стены, потолок, всё, на что встают и обо что ударяются | С коллизией и навигацией |
   | `Dressing` | Декор | Профиль коллизии **NoCollision** (сам профиль, не только галочка) и **Can Ever Affect Navigation** выключено |
   | `Fixtures` | Корпуса светильников | Как `Dressing` |
   | `Lights` | Свет | Аварийная лампа `M_LF_Emergency` обязательна в каждой комнате. Бюджет — `LevelMetrics.md` §9. Свет только подвижный |
   | `Audio` | `RoomAcoustics` и `RoomTone` | Не удалять |

3. **Проёмы.**
   - Каждый проём коннектора (300 × 350) должен остаться проходимым для игрока и Пилигрима.
   - Это проверяет `Hollow.PCG.DocksOpenings`: рамка вокруг проёма — да, балка поперёк проёма — нет.
4. **Героическая комната CoreVault.** Хотя бы одна «умирающая» панель: теневой свет с `M_LF_DyingTube`. Остальное — в рамках бюджета.
5. **Обновить свет или звук из скрипта в заблокированной комнате:**
   - сними флаг;
   - прогони скрипт (он удалит и заново поставит только свои помеченные актёры);
   - верни флаг.

## 2. Текстуры
- **Предел.** Кукаются не крупнее **2048** по большей стороне. Для исходника 4K поставь **Maximum Texture Size = 2048** или LOD Bias 1.
- **Где проверяется.** Предел действует для `/Game/Hollow` и `/HollowSector_Docks`. Лимит и пути — `Config/DefaultEditor.ini`.
- **LFS.** Каждый сохранённый бинарник — новый объект LFS (лимит GitHub Free). Перед импортом пака бери из него только нужное.

## 3. Инструмент в руке (резак, сварка)
1. **Меш.** Импортируй static mesh инструмента и в Static Mesh Editor добавь сокет **Muzzle** на срезе сопла: из него выходит луч.
2. **Данные.** В `DA_Tool_PlasmaCutter` / `DA_Tool_Welder` (раздел Cosmetics → Held):
   - **Held Mesh** — меш;
   - **Held Transform** — как он сидит в ладони;
   - **Muzzle Socket** — `Muzzle`.
   - Один меш можно назначить обоим инструментам.
3. **Сокеты рук.** Меш садится в сокет `hand_r` FP-рук и тела, это **ToolMount** в `BP_ExoFrame`. На Fab-скелете можно завести свой сокет и вписать его имя туда же.
4. **Что в руке.**
   - По умолчанию резак.
   - Во время работы — работающий инструмент, после — последний.
   - Без меша луч выходит из прежней точки перед глазами.

## 4. Монтажи Пилигрима и Хищника
1. **AnimBlueprint.** У меша врага должен быть AnimBlueprint с узлом **Slot (DefaultSlot)**. Монтажи — на скелете этого меша.
2. **Слоты.** В `DA_Enemy_IronPilgrim` / `DA_Enemy_EchoStalker` (раздел Animation → Montages):

   | Слот | Когда |
   |---|---|
   | Melee | Замах и удар (Пилигрим), удар из засады (Хищник) |
   | Breach | Удар в дверь или переборку |
   | Stunned | Оглушение миной, крутится, пока оно длится: сделай зацикленную секцию |
   | VentEnter | Вход в шахту: тело пропадёт, когда монтаж доиграет |
   | VentExit | Выход из шахты |

3. **Секция `Impact`.** В монтажах Melee и Breach поставь её на кадр удара: скорость подгоняется так, чтобы удар совпал с концом замаха из данных атаки.
4. **Без root motion.** Валидатор предупредит. Двигает тело сервер.
5. **Пустой слот** — всё как сейчас, без предупреждений.

## 5. Если тест упал
| Тест | Что значит |
|---|---|
| `Hollow.Game.Light.RoomBudgets` | Свет вне бюджета или пропала аварийная лампа (подробности в тексте ошибки) |
| `Hollow.Game.Audio.RoomAcoustics` | Удалены `RoomAcoustics` или `RoomTone` |
| `Hollow.PCG.DocksOpenings` | Проём перекрыт, в ошибке — имя актёра |
| `Hollow.Editor.ArtBudget` | Текстура больше 2048 или декор с коллизией / навигацией |
| `Hollow.Game.Tool.Mount`, `Hollow.Game.Enemy.Montages` | Ошибка в коде крепления или монтажей, а не в арте (ADR-0027) |

## 6. Склад Fab и подмена слотов ([ADR-0043](../ADR/ADR-0043-art-kit-fab-staging-cc0.md))
1. **Склад.** `Build/Scripts/create-art-staging.sh` создаёт пустой проект `~/Desktop/HollowArtStaging` вне git. Откройте его в UE 5.8, **Window → Fab → Add to Project**: паки ложатся туда, а не в игру.
2. **Подготовка.** `Build/Scripts/run-editor-python.sh Build/Python/prepare_fab_assets.py --project ~/Desktop/HollowArtStaging/HollowArtStaging.uproject`:
   - текстуры — не больше 2048, у мелких пропов (меньше 1 м) — не больше 1024;
   - мелким пропам ставится профиль `NoCollision` по умолчанию;
   - у анимаций выключается root motion;
   - вес каждого пака — в логе и в `Saved/FabReport.json` склада.
3. **Отбор.** Пак переложите в `/Game/Fab/<Pack>` (правый клик по папке → Move). В `Build/Art/fab_manifest.json`, в `packs[].keep`, впишите только нужные ассеты (зависимости скрипт найдёт сам).
4. **Перенос.** Тот же запуск с `HOLLOW_FAB_MIGRATE=1`. Скрипт откажется переносить, если `Content/Fab` игры станет тяжелее `budget_mb` (50 МБ, квота GitHub Free LFS).
5. **Подмена.** В `swaps` манифеста: `{"asset": "/Game/Hollow/Tools/PlasmaCutter/DA_Tool_PlasmaCutter", "property": "held_mesh", "value": "/Game/Fab/<Pack>/SM_Cutter"}`. Компонент блюпринта задаётся ключом `"component"`, например `{"asset": ".../BP_AetherCore", "component": "visual", "property": "static_mesh", ...}`. Затем `Build/Scripts/run-editor-python.sh Build/Python/prepare_fab_assets.py` в игре: проверка `/Game/Fab` и подмены.
6. **Проверка.** Перед коммитом — `run-tests-mac.sh --strict`. `Hollow.Editor.ArtBudget` сканирует и `/Game/Fab`.

**Сокет `Muzzle`** у меша инструмента обязателен: из него выходит луч. Если у меша Fab сокета нет, добавьте его в Static Mesh Editor на срезе сопла.
