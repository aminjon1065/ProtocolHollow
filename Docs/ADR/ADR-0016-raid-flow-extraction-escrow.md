# ADR-0016: Рейд-флоу — фазы, правило отлёта, исходы, резолвер и escrow профиля

- **Статус:** Accepted · 2026-11-20 (S3-03, подтверждено владельцем проекта, пункты 1–9 плана)
- **Связано:** CLAUDE.md §3, [ADR-0005](ADR-0005-profile-authority.md) (профиль у клиента, рейд у хоста), [ADR-0015](ADR-0015-solo-carry-claim.md) (ядро) · [Блок 2 §2.2, §2.5, §2.9](../Architecture/02_Folder_Structure_and_Class_Hierarchy.md)

## Контекст
Нужен полный цикл рейда: высадка → поиск ядра → эвакуация или смерть → дебриф → хаб. Итог рейда меняет локальный профиль игрока. Уход из рейда без итога (вылет, alt-F4, выход) не должен давать выгоды. Предметов, профиля и смерти до S3-03 в коде не было.

## Решение
1. **Фазы** (`EHollowRaidPhase`): `Assembling` → `Deploying` (3 с) → `InRaid` ⇄ `Extraction` → `Debrief` (10 с) → `ServerTravel` в хаб.
   - Сервер: `UHollowRaidFlowComponent` на `AHollowRaidGameMode`, без Tick, по таймерам.
   - Все машины: `UHollowRaidStateComponent` на GameState (push) — фаза, RaidId, конец фазы по серверному времени, живые и ядра в зоне.
   - Это один компонент вместо двух из Блока 2 (Phase + ExtractionState). Отдельного Outcome-компонента тоже нет: решения принимают чистые `HollowRaidRules`.
2. **Отлёт.** `AHollowExtractionZone` — только объём на сокете Extraction, без коллизии. Сервер опрашивает его с частотой 4 Гц явным overlap-запросом по Pawn и PhysicsBody.
   - Таймер (15 с) стартует, когда в зоне есть живой игрок, и сбрасывается, когда зона опустела. Сброс важнее отлёта на том же опросе.
   - На нуле: живой в зоне — `Extracted`, живой вне зоны — `MissingInAction`.
   - Добыча — ядра в зоне, свободные или несомые (несомое тело — query-only PhysicsBody, ADR-0015); предмет берётся из `UHollowCarryableDefinition::LootItem`.
   - Каждый эвакуированный получает добычу полностью, без деления.
   - Рейд кончается отлётом или гибелью всех.
3. **Смерть.**
   - `Health ≤ 0` → `UHollowHealthSet::OnOutOfHealth` (сервер) → `AHollowExoFrameCharacter::Die`:
     - реплицируемый `bDead`;
     - `GE_State_Dead` (`UHollowDeadEffect`: тег `Hollow.State.Dead`, блок инструментов и гаджетов);
     - отмена способностей, движение выключено, тело не блокирует живых;
     - ядро сбрасывается на месте.
   - Через 3 с игрок становится наблюдателем.
   - Урон наносится только через GE (`GE_Damage_Generic`, SetByCaller `Hollow.Data.Damage`). Downed и реанимации пока нет.
4. **Итог и резолвер.** Хост шлёт каждому `Client_ReceiveRaidResult(FHollowRaidResult { RaidId, Outcome, Loot, RaidSeconds, SquadExtracted, SquadSize })`. Машина игрока сама применяет его через `FHollowExtractionResolver` (чистая функция):

   | Исход | Лоадаут | Добыча |
   |---|---|---|
   | `Extracted` | сохраняется целиком | продаётся корпорации за кредиты |
   | `Dead`, `MissingInAction`, `Abandoned` | остаются только застрахованные слоты страхуемых предметов | теряется |
   | `SignalLost` | сохраняется целиком | теряется |

   Уже накопленные кредиты не трогаются, страховка не расходуется (флаг на слоте до UI страховки).
5. **Escrow** (`UHollowProfileSubsystem`, GameInstance, локальный; SaveGame с версией).
   - Маркер со снимком лоадаута пишется, когда машина видит RaidId в фазе после `Assembling`.
   - Разрешение:
     - итог хоста;
     - `OnNetworkFailure` у клиента — `SignalLost` (ловится по таймауту соединения, ~60 с);
     - найден при запуске или при старте другого рейда — `Abandoned`.
   - Отчёт хранится как «не просмотренный», пока игрок не закроет дебриф. HUD показывает его в рейде и снова на следующем экране (хаб, меню).
   - В автотестах подсистема не создаётся: тесты не трогают настоящий профиль.
6. **Предметы — минимально.**
   - `UHollowItemDefinition` (тип `HollowItem`): имя, тип `Hollow.Item.Type.*`, цена, страхуемость, стек.
   - Профиль: кредиты, слоты лоадаута, счётчики.
   - Лоадаут пока не управляет инструментами в рейде. `Server_SubmitLoadout` перенесён в задачу инвентаря: хосту лоадаут для итога не нужен. *S5-01 ([ADR-0030](ADR-0030-raid-inventory-loadout.md)): лоадаут сдаётся хосту и становится инвентарём рейда, итог получил список израсходованного (`Spent`).*
7. **Steam Cloud** подключается без кода: Auto-Cloud в настройках Steamworks для `Saved/SaveGames`. Это делает владелец проекта.

## Последствия
- (+) Исход и экономика проверяемы без мира (`Hollow.Economy.*`, `Hollow.Game.Raid.Rules`). Сеть передаёт один небольшой `FHollowRaidResult` на игрока.
- (+) Вылет, alt-F4 и выход ничего не дают. Уход хоста не наказывает клиента.
- (−) Отлёт по таймеру оставляет живых вне зоны (MIA), это осознанное напряжение. Альтернатива «ждать всех живых» отклонена.
- (−) `SignalLost` наступает только после таймаута соединения (60 с).
- (?) Награда пока — только кредиты за ядра. Чертежи, артефакты и налог корпорации появятся с экономикой хаба.
