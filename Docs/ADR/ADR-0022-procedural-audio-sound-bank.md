# ADR-0022: Звук — процедурные MetaSounds, один банк, «шум ↔ звук», акустика комнат

- **Статус:** Accepted · 2026-11-20 (S4-04, план и уточнения 1–8 подтверждены владельцем проекта)
- **Связано:** [ADR-0002](ADR-0002-replicate-state-not-simulation.md) (реплицируем состояние) · [ADR-0010](ADR-0010-editor-python-automation.md) (контент через Python) · [ADR-0018](ADR-0018-noise-to-ai.md) (шум → ИИ) · [ADR-0020](ADR-0020-squad-resonance.md) (`SC_Hollow_World`, `CB_Resonance`) · [Блок 3 §3.8](../Architecture/03_Physics_and_Replication_Deep_Dive.md)

## Контекст
- **Что было.** До S4-04 в игре не звучало ничего. Шум существовал только для ИИ (ADR-0018), а класс `SC_Hollow_World` с фильтром от `CB_Resonance` ждал звуков (ADR-0020).
- **Что нужно.** Звуки инструментов, дверей и проломов, шагов, Пилигрима и Хищника; реверб по комнатам; одно правило: что слышит ИИ, то и слышит игрок, и так же далеко.
- **Ограничение.** Лимит GitHub Free LFS: никаких WAV-банков.

## Решение
1. **Звуки — процедурные MetaSounds** (уточнение 1). `create_audio_assets.py` собирает 17 графов через MetaSound Builder API из спецификаций в скрипте: осцилляторы, шум, фильтры, AD-огибающие, задержки и повторы триггеров.
   - Хеш спецификации хранится в метаданных ассета. Граф пересобирается, только если спецификация изменилась.
   - Все звуки идут через `SC_Hollow_World` (уточнение 2), поэтому на них действуют фильтр Резонанса и объёмы комнат.
   - Петли: сварка, резак, гул ядра и тон комнаты. Остальные звуки — one-shot, конец графа подключён к `On Finished`.
2. **Один банк** — `DA_SoundBank` (`UHollowSoundBank`, выбирается в `UHollowAudioSettings`). Запись задаёт по тегу звук, шаблон затухания, группу concurrency, громкость и разброс высоты.
   - Тег `Hollow.Noise.*` значит, что этот шум слышит ИИ. Дальность такого звука для игрока — та же формула, что у слуха ИИ (`UHollowNoiseConfig::RangeFor`: Loudness × `ReferenceHearingRange` с потолком MaxRange). Опорный слушатель — Пилигрим, 30 м (уточнение 3).
   - Тег `Hollow.Sound.*` — звук только для игрока. Его дальность задаётся своим числом, либо ссылкой на шум: взрыв мины звучит как `Impact.Heavy`.
   - `HollowSoundRules::Check` (Data Validation банка и тесты) отклоняет:
     - шум без звука;
     - звук без ассета;
     - тег вне двух корней;
     - повтор тега;
     - ссылку на шум без правила;
     - звук без дальности;
     - у шума «второе число» дальности.
3. **`UHollowAudioSubsystem`** (Core) работает на каждой машине, кроме выделенного сервера.
   - `Play` и `PlayAttached` по тегу.
   - На каждый тег своя копия затухания: внутренний радиус берётся из шаблона `ATT_Hollow_World`, затухание идёт до тишины на дальности тега.
   - Concurrency: шаги 8, удары 6, инструменты 4.
   - Счётчики по тегу для тестов и `Hollow.Audio.Dump`.
4. **Звук идёт от реплицированного состояния, а не от серверного шума** (уточнение 4). Ни одного нового RPC. Новое на проводе — `bArmed` мины (1 бит) и `VentExitServerTime` врага (4 байта, только в первом бандле).

   | Источник | Что звучит и когда |
   |---|---|
   | Дверь | Серво на свежем переходе в Opening/Closing; удар в момент удара (blow не бывает «свежим», а дверь подписана только с BeginPlay); пролом на свежем переходе |
   | Переборка | Удар при росте `DamageStageQ`; пролом по свежести (`FreshWindowSeconds`), независимо от того, хватает ли машине бюджета Chaos показать разрушение |
   | Ядро | Гул с BeginPlay; удар при отпускании |
   | Инструменты | Петля в beam cue по `NoiseTag` инструмента |
   | Мина | Сигнал по `OnRep_Armed`; взрыв |
   | Хищник | Решётка при входе в шахту (OnRep), при выходе и при появлении от директора (`EmergeFromVent`). В шахте Хищник ни для кого не релевантен, поэтому клиент получает нового актора. Его первый бандл несёт `VentExitServerTime` (`COND_InitialOnly`), и свежий выход звучит в BeginPlay |
   | Враги | Голос замаха — `UHollowEnemyDefinition::WindupSound` в wind-up cue |

   Опоздавший игрок не слышит ничего из прошлого:
   - OnRep из первого бандла не играет (`HasActorBegunPlay`);
   - момент из первого бандла играет, только если он не старше `FreshEventSeconds` (1 с).
5. **Шаги** — `UHollowFootstepAudioComponent` на каждой машине, для любых персонажей: скорость и режим движения чужих персонажей реплицируются.
   - У игрока тег `Hollow.Noise.Footstep`: каденция и громкость по скорости — те же, что у шума шагов. Шаг вприсядку беззвучен и для ИИ, и для людей.
   - У врагов тег `Hollow.Sound.Footstep.*` и своя `FHollowFootstepCadence` в DA:
     - Пилигрим: шаг раз в 0,7 с, слышен от 60 см/с;
     - Хищник: раз в 0,28 с.
   - Валидатор DA требует, чтобы враг был слышен уже на скорости патруля. Эту дыру нашёл смоук: по порогам игрока (200 см/с) Пилигрим, патрулирующий на 180, ходил беззвучно.
6. **Акустика комнат** (уточнения 5–6). В каждом из 8 уровней комнат доков стоят:
   - штатный `AAudioGameplayVolume` ровно по габариту комнаты;
   - `UReverbVolumeComponent` с пресетом по типу комнаты:
     - CoreVault — `RE_Vault`, 3,2 с;
     - большие комнаты — `RE_Hangar`;
     - проходные — `RE_Corridor`, 0,9 с;
   - `UFilterVolumeComponent`: звук снаружи режется до 1,5 кГц;
   - `AmbientSound` с тоном комнаты (box-затухание по комнате, CoreVault — свой тон).

   Подробности:
   - `SC_Hollow_World` получил `bApplyAmbientVolumes`.
   - Уровень пересохраняется только при изменении своей спецификации (маркер `HollowAudioSpec`).
   - **Отступление от плана.** `AHollowRoomAcousticsVolume` не создан: `AAudioGameplayVolume` объявлен как MinimalAPI, и его конструктор не экспортирован, так что наследника в другом модуле не слинковать. Компоненты-мутаторы ставит в уровень хелпер `UHollowAssetAuthoring::AddInstanceComponent`.
7. **Стены для ИИ** (уточнение 7). `UHollowNoiseConfig::InterRoomRange` = 0,6: шум из другой комнаты топологии слышен на 60 % своей дальности.
   - Правило — `ReachesThroughWalls`; фильтр стоит в `AHollowAIController`.
   - В той же комнате и вне комнат решает сам слух.
   - Игрок слышит такой шум приглушённым фильтром объёма.
8. **Данные и отладка** (уточнение 8):
   - `[/Script/HollowCore.HollowAudioSettings]`: `SoundBank`, `ReferenceHearingRange=3000`, `FreshEventSeconds=1.0`;
   - `Hollow.Audio.Dump` печатает события по тегам, активные голоса и объём комнаты, в которой слушатель.

## Последствия
- (+) Один источник правды: дальность звука и дальность слуха ИИ считаются одной функцией из одних данных, а тест сверяет её на реальных ассетах.
- (+) Звук не стоит сети: каждая машина проигрывает его из того состояния, которое уже реплицируется.
- (+) **LFS.** Весь S4-04 — 2,2 МБ бинарного контента:
  - 17 MetaSounds — 1,73 МБ, около 104 КБ на граф: документ MetaSound хранит метаданные классов узлов;
  - банк, затухание, 3 группы concurrency и 3 реверба — 22 КБ;
  - 8 пересохранённых уровней — 0,44 МБ;
  - DA — 13 КБ.

  Для сравнения: секунда моно-WAV 48 кГц / 16 бит — 94 КБ, то есть все звуки весят как 19 секунд записи.
- (+) **Критерий S4-04:**
  - `Hollow.Core.Audio.Bank`, `Hollow.Core.Noise.ThroughWalls`;
  - `Hollow.Game.Audio.{Consistency, Events, RoomAcoustics}`, `Hollow.Game.AI.InterRoomHearing` (настоящая сварка за стеной);
  - смоук со звуком в одном процессе;
  - смоук в двух процессах с 150 мс: у клиента те же события по тегам, что у хоста;
  - смоук Хищника: мина клиента оглушает его, он уходит в шахту и выходит из другой; у клиента решётка звучит оба раза, а сигнал мины, взрыв, вопль замаха и шаги совпадают с хостом.
- (−) **Окклюзии по геометрии нет.** Стена ослабляет шум по топологии комнат. Открытая дверь между комнатами тоже даёт 60 %.
- (−) Голос (VOIP) в S4-04 не входит.
- (?) **Звучание никто не слушал.** На M4 в смоуке микшер CoreAudio работает и голоса активны, но устройство вывода определяется как «Unknown». Громкости, тембры и реверб надо настроить на слух в редакторе.
- (?) Стоимость MetaSounds на CPU не измерена; это часть трассы S4-05. Неслышимые петли виртуализируются (режим `Restart` по умолчанию).
- (?) Под `-nosound` при сохранении MetaSound пишется предупреждение `PreSaveAsset ... doing nothing`. Оно безвредно: вне кука пропускается только обновление окон редактора.
