# ADR-0010: Headless-автоматизация контента через PythonScriptPlugin (только Editor)

- **Статус:** Accepted · 2026-11-19 (подтверждено владельцем проекта)
- **Связано:** ADR-0009 · CLAUDE.md §2 · [Блок 1](../Architecture/01_Module_and_Plugin_Map.md)

## Контекст
Карты (`.umap`) и DataAssets (`.uasset`) — бинарные ассеты, их нельзя написать как текст. Без скриптов редактора каждую карту или DataAsset пришлось бы создавать вручную, что тормозит S1-03 (`L_Boot`, `L_Hub_Dev`), S1-07 (greybox-кит) и далее.

## Решение
1. В `.uproject` включён `PythonScriptPlugin` с `"TargetAllowList": ["Editor"]`. Плагин и Python **не попадают** в игровые и упакованные таргеты.
2. Скрипты лежат в `Build/Python/`. Это **идемпотентные** инструменты: повторный запуск не ломает и не дублирует ассеты. Запускаются headless через `Build/Scripts/run-editor-python.sh <script.py>`, что под капотом выполняет `UnrealEditor-Cmd -ExecutePythonScript … -unattended -nullrhi`.
3. Правила CLAUDE.md распространяются на `.py`: ASCII-only, LF. Код **геймплея** на Python не пишется никогда, только инструменты контента.
4. Результат скрипта (ассеты) коммитится, как если бы его сделали руками. Сам скрипт остаётся воспроизводимым «рецептом».

## Последствия
- (+) Claude Code и CI могут создавать и обновлять контент без UI; ассеты воспроизводимы.
- (−) API редакторских подсистем Python иногда меняется между версиями. Мы зафиксированы на 5.8.x (ADR-0008), так что риск низкий.
