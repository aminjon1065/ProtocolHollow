# ADR-0014: Chaos-переборки — панели по зонам, презентация на каждой машине, переборка не отрезает комнаты

- **Статус:** Accepted · 2026-11-20 (S3-01, подтверждено владельцем проекта, пункты 1–7 плана)
- **Связано:** CLAUDE.md §3 и §5, [ADR-0002](ADR-0002-replicate-state-not-simulation.md) (состояние, а не симуляция), [ADR-0003](ADR-0003-sector-manifest-replication.md) (генератор), [ADR-0004](ADR-0004-runtime-navmesh-door-links.md) (навмеш), ADR-0010 (бинарный контент скриптами) · [Блок 3 §3.4, §3.7](../Architecture/03_Physics_and_Replication_Deep_Dive.md)

## Контекст
Генератор уже ставит соединения вида Bulkhead (S2-01), но до S3-01 на них стояла заглушка. Нужна переборка, которую ломают структурным уроном (Железный Пилигрим, позже молот и взрывы). Пролом должен быть одинаковым у всех игроков, переживать late-join и смену relevancy, укладываться в бюджет кадра и сразу менять навигацию. Осколки при этом не должны толкать Pawn, ядра и ИИ.

## Решение
1. **Геймплейная геометрия — рамка и панель на каждую зону** (`UHollowBreachableDefinition`, тип `HollowBreachable`). Это вместо пары `IntactMesh`/`BrokenFrameMesh` из первой версии §3.4. Панель зоны блокирует проход, пока бит зоны не стоит в реплицированном `ZoneMask`. Поэтому коллизия при любой маске одинакова на всех машинах по построению. Проход открыт, когда сломаны все зоны с `bRequiredForPassage`.
   - **Plate:** одна зона на весь проём.
   - **Twin:** две половины. Первая сломанная половина даёт дыру, но состояние остаётся `Weakened`.
   - Удар попадает в ближайшую целую зону. Один удар ломает не больше одной зоны.
2. **Состояние `FHollowBreachNetState`, 9 байт:**
   - состояние и маска зон в одном байте;
   - `DamageStageQ` — доля потерянной прочности, по ней рисуются трещины;
   - направление удара: yaw и pitch, по байту на каждый;
   - `BreachServerTime` и `TransitionSerial`.

   Хранится в `UHollowStructuralIntegrityComponent`: push model, dormancy, `FlushNetDormancy` + `ForceNetUpdate` на изменениях. Прочность зон есть только на сервере. Источник урона — интерфейс Core `IHollowStructural`.
3. **Презентацию каждая машина выбирает сама, включая хост.** Решает `UHollowDestructionBudgetSubsystem` через чистую политику `HollowBreachPolicy::Choose`.
   - **Full** — только если пролом свежий (`Age < FreshWindowSeconds`), ближе `MaxSimDistance` к локальной камере, панель недавно рендерилась, есть слот и хватает бюджета тел. Тогда на месте зоны появляется GC зоны (`SetIsReplicated(false)`, `bEnableReplication = false`, начальная скорость вдоль удара). Через `MaxDebrisLifetime` GC удаляется, остаётся щебень.
   - **Snap** во всех остальных случаях (late-join, далеко, не видно, бюджет исчерпан, на машине нет камеры): сразу статичный щебень.
   - Бюджеты — таблица по `sg.EffectsQuality` (`UHollowDestructionBudgetConfig`, DefaultGame.ini). Таймеры есть, Tick нет. GC-ассеты подгружаются async в `BeginPlay`, только на машинах, которые рендерят.
4. **Канал `HollowDebris`.** У канала ответ по умолчанию Block: стены, полы и двери останавливают осколки. У профиля `HollowDebris`:
   - `PhysicsOnly`;
   - игнорирует Pawn, PhysicsBody, Vehicle, Destructible, Visibility, Camera и Interaction;
   - `bCanEverAffectNavigation = false`.

   Осколки не двигают игроков, врагов и ядра и не перекрывают трейсы инструментов, линию взгляда ИИ и взаимодействие. Щебень вообще без коллизии.
5. **Навигация** (сервер). Как у двери, проём через стену режет Null-бокс (`NavBlocker`), а nav-link в проёме включён всегда:
   - до пролома area связи `UHollowNavArea_BulkheadIntact`: Standard исключён, Heavy платит ×12 (данные `NAV_Filter_*`). Это отличие от §3.7 («связь выключена»): Пилигрим (S3-04) может строить маршрут через пролом переборки;
   - в момент пролома area сразу становится `UHollowNavArea_Doorway` (`SetEnabledArea` + `K2_ReplaceAreaInOctreeData` + `NotifyLinkChanged`, O(1));
   - через `BlockerRemovalDelay` блокер уходит из nav-октодерева (`SetCanEverAffectNavigation(false)`), и тайлы вокруг проёма пересобираются async.
6. **Генератор: переборка не отрезает комнаты** (CLAUDE.md §5).
   - `AssignKinds` выбирает переборки из перемешанного списка кандидатов и пропускает те, без которых граф перестал бы быть связным.
   - Приёмка требует `ComponentsWithoutBulkheads == 1`.
   - Петли по-прежнему считаются по всем соединениям: переборка — закрытая петля, которую откроет Пилигрим.
   - Проверка пути Spawn → Extraction после сборки (S2-02) идёт фильтром Standard.
7. **Варианты по seed.** У `FHollowConnectionActorRule` новое поле `Variants`. Сервер выбирает вариант по `HollowRandom::DeriveSeed(Seed, ConnectionIndex)`, так что для QA один seed всегда выглядит одинаково. Класс актёра реплицируется сам.
8. **Greybox GC собирает C++-хелпер** `UHollowGeometryCollectionAuthoring` (HollowEditor):
   - вызывается из `create_bulkhead_assets.py`;
   - режет бокс через Voronoi `FFractureEngineFracturing::VoronoiFracture` с фиксированным seed;
   - кластеризация выключена: каждый кусок — отдельное тело с самого начала, это всплеск, а не кластер, который нужно ломать;
   - лежащие куски удаляются по сну.

   Плагин `Fracture` уже подключался через `GeometryCollectionPlugin`, теперь он указан в `.uproject` явно (Mac и Win64, без C++-зависимостей в рантайме). Боевые разломы делает художник в Fracture Editor или Dataflow.

## Последствия
- (+) По сети идут 9 байт и 1–3 изменения за рейд. Late-join получает Snap бесплатно, проход и навигация у всех одинаковы.
- (+) Бюджет разрушений у каждой машины свой: слабая машина и сервер без камеры не платят за симуляцию.
- (+) Новая разрушаемая вещь (баррикада, дверь от Пилигрима) — это реализация `IHollowStructural` и, по желанию, тот же компонент целостности.
- (−) Осколки на разных машинах разлетаются по-разному. Это осознанно (ADR-0002): одинаковы только проход, коллизия и навигация.
- (−) Full виден только с отрисовкой. Headless-тесты проверяют политику, Snap, профиль и коллизию, а Full проверяется в игре с `-RenderOffScreen`.
- (−) PlanarCut ремеширует поверхности разреза с шагом точек шума даже при нулевой амплитуде. Хелпер ставит шаг равным размеру бокса, иначе greybox-GC весил бы десятки мегабайт.
- (?) Шум пролома (`Hollow.Noise.Structural.Breach`) подключит S3-05, удары Пилигрима — S3-04, «геройский» пролом через Chaos Cache — S3-07.
