# ADR-0003: Генерация сектора — seed и реплицируемый манифест, декор в редакторе

- **Статус:** Accepted · 2026-11-19 (Proposed → Accepted: подтверждено владельцем проекта, Q1–Q6)
- **Связано:** CLAUDE.md §5 (PCG Level Generation) · [Блок 2 §2.6](../Architecture/02_Folder_Structure_and_Class_Hierarchy.md)

## Контекст
CLAUDE.md §5: «All sector generation must be deterministic from an int32 Seed replicated by GameState so server and clients assemble identical geometry». Если клиенты сами прогоняют генератор по seed, это хрупко: порядок выдачи Asset Registry в разных билдах, порядок `TMap`, float-математика, рассинхрон версий контента. Любая из этих мелочей даёт другой уровень у одного из игроков.

## Решение (уточнение правила CLAUDE.md §5)
1. Генератор **детерминирован по `int32 Seed`**. Это гарантируется тестами: SeedParity, NoOverlap, PathSpawnToExtraction, MinLoops. Используется только целочисленный грид и пул комнат, отсортированный по `PrimaryAssetId`.
2. Генератор запускает **только сервер**. Результат — компактный `FHollowSectorManifest` (комнаты как `TObjectPtr` на DA, клетки, повороты, соединения; меньше 2 KB). Он реплицируется вместе с `Seed` и `LayoutHash` через `UHollowSectorStateComponent` на GameState (push, без `COND_InitialOnly`, потому что манифест появляется после первой репликации GameState).
3. Клиенты собирают уровень **из манифеста** и сверяют `LayoutHash` в `Server_ReportSectorReady`.
4. `Seed` по-прежнему реплицируется и используется для производных `RoomSeed = Hash(Seed, RoomIdx)` (декор) и для воспроизведения багов, ежедневных контрактов и шаринга seed'ов.
5. Комнаты — Level Instances со статичной геометрией, светом и звуком; стримятся локально на каждой машине. Геймплейные актёры (двери, переборки, лут, ядра, эвакуация) **спавнит сервер** как реплицируемые актёры по сокетам и коннекторам. Совпадения имён актёров между сервером и клиентом не требуется.
6. PCG Framework работает внутри комнат, для декора: в первую очередь в редакторе (`DressingVariants`), в рантайме — только косметика без геймплейной коллизии.

## Последствия
- (+) Целый класс рассинхронов исчезает; трафик — один раз меньше 2 KB.
- (+) Детерминизм по seed сохранён и проверяется тестами.
- (−) Клиент не может «собрать уровень заранее» до прихода манифеста. Задержка — один RTT, прячется за загрузкой.
- Подтверждено (Q1); CLAUDE.md §5 обновлён.
