# Блок 4 — План вертикального среза (Фаза 1, 8 недель, 4 спринта по 2 недели)

> Статус: **Proposed v0.1** · 2026-11-19

---

## 4.0 Честная рамка

8 недель на такой срез при соло-разработке — **агрессивный** срок. Он реален только при трёх условиях:
1. **Жёсткий MoSCoW.** В каждом спринте Must занимает ≤ 8.25 дня из 10. Остаток — буфер и Should.
2. **Cut-list заранее.** Если к концу спринта отстаём, режем по списку, а не по ситуации.
3. **Claude Code пишет каркас, бойлерплейт и тесты, ты интегрируешь и «чувствуешь».** Ассеты берём с Fab и Megascans, финальное качество — только у одной «геройской» комнаты.

**Допущения:** ~40 часов фокусной работы в неделю, 1 dev-day = 1 оценочная единица, UE 5.8.x, Steam AppID 480 до покупки своего.

### Цель среза (Exit Criteria)

| # | Критерий | Как меряем |
|---|---|---|

| E2 | Соло запускается тем же билдом и тем же путём кода | listen-сессия на 1 игрока |
| E3 | Процедурный мини-сектор «Орбитальные доки»: 8–10 комнат из пула 8 модулей, петли, путь Spawn → Extraction | автотесты генератора + 10 seed'ов руками |
| E4 | Инженер-проходчик: резак (замки, сварка), сварка дверей, импульсная мина | плейтест |

| E6 | Железный Пилигрим: слышит, преследует, ломает заваренные двери через nav-link | плейтест |
| E7 | Прототип Эхо-Хищника: голос и шум, Резонанс, heatmap-засада, вентиляция, неуязвимость, оглушение импульсом | плейтест |

### Метрики greybox (стартовые, валидируются в S1)
Клетка грида 400 uu · проём 300 × 350 uu (проходят Пилигрим и кооп-переноска) · коридор ≥ 300 uu · потолок ≥ 400 uu · вент-люк 90 × 90 uu · шаг лестниц и рамп совместим с CMC (`MaxStepHeight 45`).

## 4.1 Критический путь

```
S1-03 Steam ─────────────────────────────────────────────────────────────► S4-06 Steam-билд
S1-04 CMC ─► S3-02 соло-переноска ─► S3-06 кооп-переноска
S1-05 GAS ─► S2-03 инструменты ─► S2-04 дверь ─► S2-05 nav двери ─► S3-04 Пилигрим ─► S4-01 Хищник
S1-07 кит ─► S2-01 генератор ─► S2-02 сборка ─► S3-01 переборки ─► S4-03 свет
```
Если Steam-сессия не поднялась к концу S1, это **стоп-сигнал**. Не идём дальше, пока не работает (Null OSS в PIE эту проблему не покажет).

## 4.2 Ритуалы (соло)

| Когда | Что |
|---|---|
| Ежедневно | PIE 2–3 клиента + Network Emulation *Bad*; `Build/RunTests.sh` перед коммитом |
| Каждую пятницу | упакованный билд и Steam-сессия на 2 машинах; 15 минут «ощущений» с заметками |
| Конец спринта | трасса Insights у хоста с 4 игроками (или 2 + боты-манекены); ретро в `Docs/Sprints/S<N>.md`; актуализация cut-list |
| Новое архитектурное решение | ADR в `Docs/ADR/` (CLAUDE.md §8) |

## 4.3 Definition of Done для каждой задачи (из CLAUDE.md)
Ноль новых warnings · нет `LogTemp`, мёртвого кода и магических чисел (всё в DA, DT или DeveloperSettings) · сетевые фичи проверены в PIE на 2+ игроках (Listen + Client) с эмуляцией сети · тесты добавлены и зелёные · `bCanEverTick = false` по умолчанию, у каждого исключения есть комментарий-обоснование.

## 4.4 Что сознательно НЕ входит в VS
Хаб «Скит» как уровень (в VS это меню-лобби) · крафт и верстак (только данные предметов) · страховка в UI (логика есть в резолвере) · классы 2–4 · дрон · лебёдка · Zero-G · Шептуны (рой) · секторы II–III · таланты · мета-прогрессия корабля · Steam Deck-сертификация (только пресет Low как задел).
