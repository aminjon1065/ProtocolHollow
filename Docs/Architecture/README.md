## Ключевые решения на одном экране
1. **UE 5.8.x**, заморожена до 1.0 (5.8 — вероятно, последняя UE5; MegaLights в Production Ready; Lumen Lite для Low и Steam Deck).
2. **Реплицируем состояние, а не симуляцию.** Осколки Chaos — локальная косметика, форма пролома задана заранее, геройские проломы идут из Chaos Cache.
3. **Инструменты:** серверный трейс 10 Гц по виду игрока (без лишнего RPC), прогресс считается по серверному времени, топливо и нагрев — через GE.
4. **Двери:** пакет состояния ~10 байт, push + dormancy, створка вычисляется по серверному времени, навмеш через nav-link (смена area без пересборки тайлов).
5. **Ядра:** «виртуальные носилки». Трансформ ядра не реплицируется; штраф скорости живёт в saved moves; в коопе включается client-auth с санитарной проверкой.
6. **Сектор:** сервер генерирует по seed, клиенты собирают по реплицируемому манифесту (< 2 KB), PCG-декор в основном запекается в редакторе.
7. **ИИ:** Director + простые StateTree; «память» Хищника — heatmap по графу комнат; вентиляция — абстрактный граф.
8. **Голос → ИИ:** громкость микрофона уходит на сервер как `uint8` и не зависит от voice-бэкенда.
9. **Профиль** хранится у клиента, рейдом управляет хост; escrow и исход «Signal Lost» при отключении хоста.
10. **Не берём** в v1: Iris, RepGraph, Mover, ресимуляцию физики, Mass, World Partition для рейда, Wwise/FMOD.

## Прогресс
- **S1-01 «Бутстрап»** — `.uproject` (UE 5.8), 10 модулей, лог-категории, нативные теги с compile-time проверкой неймспейса, `UHollowAssetManager`, автотесты `Hollow.Core.*`, Git + LFS, скрипты `Build/Scripts/` (Mac-сборка с гейтом warnings, упаковка Win64 под 16 ГБ RAM).
- **S1-02 «Тест-харнесс»** — `Build/Scripts/run-tests-mac.sh` и парный `run-tests-win64.ps1` (+ `.cmd`) на общем модуле `HollowBuild.psm1`: инкрементальная сборка с гейтом warnings → headless `Automation RunTests Hollow.` → сводка `index.json`/`index.html`. Коды выхода: 0 ok · 1 упал/не запущен тест · 2 окружение · 3 нет отчёта · 4 фильтр пуст · 5 редактор вернул ≠0 · 6 таймаут · 7 сборка. На Mac проверены ветки 0/1/4/6 и `--strict`.
- **S1-03 «Steam-сессии»** — свой `UHollowSessionSubsystem` поверх OSSv1 (ADR-0006): host (Solo / InviteOnly / FriendsOnly → private / private / friends-only Steam-лобби), принятие инвайта → `JoinSession` → `ClientTravel`, leave, обработка обрывов; чистые правила `HollowSessionRules` + 3 автотеста `Hollow.Net.Session.*`; гейт `AHollowGameModeBase::PreLogin` (вход только в хаб, соло закрыто, лимит 4); SteamSockets + IpNetDriver fallback; dev-команды `Hollow.Session.Host|Invite|Leave|Status`; карты `L_Boot` / `L_Hub_Dev` созданы headless через PythonScriptPlugin (ADR-0010). На Mac проверено: сборка unity и без unity без warnings, 5/5 тестов, сквозной тест двух процессов (вход в InviteOnly проходит, в Solo — отказ PreLogin). Живой Steam-тест Mac ↔ Windows: [`Docs/QA/SteamLiveTest.md`](../QA/SteamLiveTest.md).
- **S1-04 «ExoFrame»** — `AHollowExoFrameCharacter` (штатный First Person Rendering 5.8: FP-руки + TP-тело, камера на сокете head, ADR-0011), `UHollowCharacterMovementComponent` с `FSavedMove_Hollow` (спринт = `FLAG_Custom_0`, без склейки ходов с разным спринтом, сохранение запроса при replay), `UHollowMovementTuning` + чистая модель скорости, `UHollowInputConfig` (привязка по тегам `Hollow.Input.*`), контент через `create_exoframe_assets.py` (IA, `IMC_Raid` клав/мышь + геймпад, DA, `BP_ExoFrame`, `BP_GameMode_Hub`); плейсхолдеры Manny импортируются скриптом из шаблонов движка, в git не попадают. Тесты: 9/9 в строгом режиме. Попутно исправлены две ошибки конфигурации с S1-01: отсутствующее правило `GameFeatureData` в AssetManager и viewport-клиент CommonUI (`CommonGameViewportClient`).
- **S1-05 «GAS core»** — `UHollowAbilitySystemComponent` (OnSpawn-активация при смене аватара), `UHollowAttributeSetBase` + Health (с мета `IncomingDamage`/`IncomingHealing`) / Survival / Resonance / Tool, `UHollowGameplayAbility` (ActivationPolicy, LocalPredicted, InstancedPerActor), `UHollowAbilitySet` (+handles), `AHollowCharacterBase`; ASC и наборы на `AHollowPlayerState` (Mixed, `PlayerStateNetUpdateFrequency=60` в настройках); ExoFrame перенесён на `AHollowCharacterBase`, наборы способностей выдаются на время владения pawn. - **S1-06 «Взаимодействие»** — `IHollowInteractable` (Core, только C++), канал трассировки `Interaction`, `UHollowInteractionComponent` (фокус по таймеру 15 Гц из глаз pawn, `Server_Interact` с мягкой валидацией через чистые `HollowInteractionRules`), `UHollowInteractionSettings`, универсальный `AHollowSwitch` (push model, dormancy, OnRep → лампа); `BP_Switch` перед каждой PlayerStart в `L_Hub_Dev`; dev-команды `Hollow.Interact`, `Hollow.Dev.RunAfter`, отладка `Hollow.Interaction.Debug`. - **S1-07 «Greybox-кит и метрики»** — `Docs/QA/LevelMetrics.md` (клетка 400, этаж 400, стены 20 внутри footprint, проём 300 × 350, вент 90, агент Пилигрима 80/280), `UHollowLevelMetrics` (единый источник чисел), `UHollowRoomDefinition` (primary asset `HollowRoom`, Data Validation), чистые `HollowRoomRules`; 8 комнат «Орбитальных доков» (`LV_Docks_*` + `DA_Room_Docks_*`) из одной спецификации `create_docks_greybox.py`.
