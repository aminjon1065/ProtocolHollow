## Ключевые решения на одном экране
1. **UE 5.8.x**, заморожена до 1.0 (5.8 — вероятно, последняя UE5; MegaLights в Production Ready; Lumen Lite для Low и Steam Deck).
2. **Реплицируем состояние, а не симуляцию.** Осколки Chaos — локальная косметика, форма пролома задана заранее, геройские проломы идут из Chaos Cache.
3. **Инструменты:** серверный трейс 10 Гц по виду игрока (без лишнего RPC), прогресс считается по серверному времени, топливо и нагрев — через GE.
4. **Двери:** пакет состояния ~10 байт, push + dormancy, створка вычисляется по серверному времени, навмеш через nav-link (смена area без пересборки тайлов).
5. **Ядра:** «виртуальные носилки». Трансформ ядра не реплицируется; штраф скорости живёт в saved moves; в коопе включается client-auth с санитарной проверкой.
6. **Сектор:** сервер генерирует по seed, клиенты собирают по реплицируемому манифесту (< 2 KB), PCG-декор в основном запекается в редакторе.
7. **ИИ:** Director + простые StateTree; «память» Хищника — heatmap по графу комнат; вентиляция — абстрактный граф.
8. **Голос → ИИ:** громкость микрофона уходит на сервер как `uint8` и не зависит от voice-бэкенда.
9. **Профиль** хранится у клиента, рейдом управляет хост; escrow и исход «Signal Lost» при отключении хоста.
10. **Не берём** в v1: Iris, RepGraph, Mover, ресимуляцию физики, Mass, World Partition для рейда, Wwise/FMOD.
